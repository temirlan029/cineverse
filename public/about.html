METU

О ПРОЕКТЕ

CineVerse — многофункциональный веб-сайт, созданный как школьный проект. Объединяет поиск фильмов, аниме, мини-игры, музыку, новости и погоду в одном месте.

🎬

Кинопоиск

Поиск фильмов по названию через Kinopoisk API. Рейтинги, описания, постеры. Возможность добавлять фильмы в избранное.

🎌

Аниме

Поиск и просмотр информации об аниме через Jikan API. Топ рейтинга, жанры, эпизоды и описания.

🎮

Мини-игры

Коллекция браузерных игр: 2048, Тетрис, Змейка, Hextris, Floppy Bird и PROXX — играй прямо на сайте.

🎵

Музыка

Подборка Spotify-плейлистов разных жанров. Слушай прямо на сайте через встроенный плеер.

📰

Новости

Актуальные новости из RSS-лент ведущих российских СМИ: Лента.ру, РБК, РИА Новости.

🌤️

Погода

Прогноз погоды для любого города через wttr.in. Без ключей API, быстро и просто.

👤

Авторизация

Вход через Google и VK с помощью OAuth 2.0. Безопасная серверная авторизация через Passport.js.

🌙

Тёмная / светлая тема

Переключение темы с сохранением выбора. Тёмная тема по умолчанию, оптимально для глаз.
